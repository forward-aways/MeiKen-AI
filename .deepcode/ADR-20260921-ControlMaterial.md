# ADR-20260921：控件材质单一事实源（胶囊 / 图标按钮）+ 胶囊图标精简

- 状态：待评审（Phase 2.5 完成，等待 CHECKPOINT）
- 日期：2026-09-21
- 影响面：`frontend/src/assets/main.css`、`components/AgentOptions.vue`、`components/TopBarOptions.vue`、`components/KBPill.vue`、`components/MessageInput.vue`、`components/Dashboard.vue`、`src/__tests__/material.test.js`

---

## 1. 背景与问题陈述

用户验收发现两件事：

1. 落地页输入框的三个胶囊（模型 / 思考 / 强度）左侧图标冗余，希望去掉。
2. 输入框右侧的胶囊与按钮"还是老的"——即未跟上亚克力材质升级。

第 2 点是**上一个 ADR（LandingInputMaterial）同一根因的延续**：上次只把"输入框表面"收敛为单一事实源，**没有覆盖"控件材质"（胶囊、图标按钮）**，因此控件层继续漂移。

---

## 3. 根因分析

### 3.1 5 Whys

| 层 | 问题 | 回答 |
|---|---|---|
| 1 | 为什么知识库胶囊和附件按钮是旧样式？ | 材质升级时只改了部分控件 |
| 2 | 为什么只改了一部分？ | 胶囊/按钮材质在**每个组件内各自声明**，没有共享类 |
| 3 | 为什么没有共享类？ | 上一个 ADR 只抽象了"输入框表面"，未抽象"控件材质" |
| 4 | 为什么抽象范围会漏？ | 以"组件"为单位抽象，而非以"**材质语义**"为单位 |
| 5 | 为什么会必然再次漂移？ | 只要存在第二份材质声明，下一次升级仍会遗漏 |

### 3.2 根因分层表

| 层级 | 内容 | 证据 |
|---|---|---|
| 症状 | KB 胶囊与附件按钮为旧样式；胶囊图标冗余 | 用户验收 |
| 直接原因 | 控件材质未纳入上次的共享层 | `KBPill.vue:77-109`、`MessageInput.vue:131`、`Dashboard.vue:190` |
| **根因** | **控件材质（胶囊 / 图标按钮）没有单一事实源**：同一语义在 5 处各自声明（2 份新 + 3 份旧） | 上述 5 处实现；`.ao-btn` 与 `.to-btn` 配方逐字相同 |

### 3.3 泛化判断

| 问题类型 | 一次性 / 一类 | 代表输入 | 反例 | 非适用场景 |
|---|---|---|---|---|
| 控件材质漂移 | **一类** | 胶囊、图标按钮 | 发送按钮为**主操作**（实心强调色），语义不同，不应玻璃化 | 徽标/开关/角标等非"可点击表面" |

> 结论：规则是"**可点击表面**（输入框、胶囊、图标按钮）必须共用材质类"；主操作按钮与角标不在此列。

## 4. 设计方案

### 4.0 层叠（elevation）语义 —— 用户确认的设计方向（**已修订**）

**初版设计（嵌入/凸起混合 + 强拟物）被用户否决**：

> "输入框应该是突出的才对，拟物风有点不太好看，还是毛玻璃好看。"

据此修订为：**全部控件统一为"凸起 + 毛玻璃"**，不做嵌入、不做重拟物（去掉反向渐变、
内阴影、底部暗线等硬拟物手法）。区分度通过**模糊半径 / 投影强度 / 尺寸形状**的
梯度体现，而不是通过"凹/凸"对立。

| 层级 | 控件 | 模糊 | 投影 | 说明 |
|---|---|---|---|---|
| 主表面 | 输入框 `.glass-input` | `blur(28px)` | 中等外投影 | 凸起毛玻璃，顶部内高光 |
| 控件 | 胶囊 `.glass-pill` / 图标按钮 `.glass-icon-btn` | `blur(22px)` / `blur(18px)` | 轻外投影 | 同族，尺寸小故投影更轻 |
| 轻量 | 提示词胶囊 `.glass-chip` | `blur(20px)` | 最轻 | 与输入框区分，但同族 |

不变量（修订）：
- I1：同一语义的控件**必须**引用同一共享类，不得各自声明材质。
- I2：区分度来自**强度梯度**（模糊/投影/尺寸），而非方向对立。
- I3：**禁止**在遮罩层（overlay）与卡片（card）上同时使用 `backdrop-filter`（见
  `ADR-20260921-ModalBackdropFilter`）。
- I4：发送按钮为主操作（实心强调色），不参与本系统。

### 4.1 新增共享材质类（`main.css`）

```css
/* 嵌入：输入框 */
.glass-input { /* 反向渐变 + inset 顶部阴影 + inset 底部高光 + --noise-subtle + blur(28px) */ }
.glass-input:focus-within { /* accent 边 + inset 阴影收窄 + 3px 焦点环 */ }

/* 凸起：胶囊 */
.glass-pill { /* 正向渐变 + inset 顶部高光 + inset 底部暗线 + 外投影 + --noise-medium + blur(22px) */ }
.glass-pill:hover { /* translateY(-1px) + accent 边 + 投影加深 */ }
.glass-pill.active { /* accent 文字/边 + 高光强化 */ }

/* 凸起：圆形图标按钮 */
.glass-icon-btn { /* 与 .glass-pill 同族；圆角由组件给（50%） */ }

/* 凸起·轻：提示词胶囊 */
.glass-chip { /* 同族但更透、投影更浅 */ }
```

尺寸、圆角、内边距仍由组件决定；**材质与层叠**来自共享类。

### 4.2 应用替换

| 组件 | 改动 |
|---|---|
| `AgentOptions.vue` | `.ao-btn` 材质删除 → `class="ao-btn glass-pill"`；**移除三个胶囊的前置图标 SVG**（保留文字 + 下拉箭头） |
| `TopBarOptions.vue` | `.to-btn` 材质删除 → `glass-pill` |
| `KBPill.vue` | `.search-capsule` 旧材质删除 → `glass-pill`（旧平面 → 凸起玻璃） |
| `MessageInput.vue` | `.icon-btn` 材质删除 → `glass-icon-btn`（旧平面 → 凸起玻璃） |
| `Dashboard.vue` | `.attach-btn` 材质删除 → `glass-icon-btn`；`.prompt-chip` 材质删除 → `glass-chip` |
| `main.css` | `.glass-input` 由"半透明玻璃"升级为**嵌入**（反向渐变 + 内阴影） |

### 4.3 图标移除的语义说明

移除的是三个胶囊的**前置装饰图标**（模型=方块、思考=灯泡、强度=脉冲），保留胶囊文字与右侧下拉箭头。
理由：文字标签已完全表意（"跟随智能体"/"标准"/"中"），图标不承载额外信息，且知识库胶囊（本就无图标）与之一致。

### 4.4 复杂度

纯 CSS/模板重构，无运行时复杂度变化；CSS 去重（消除 3 份胶囊配方 + 2 份按钮配方 + 1 份提示词配方）。

## 5. 备选方案与取舍

| 决策点 | 方案 | 优点 | 缺点 |
|---|---|---|---|
| 材质收敛 | **A 共享 `.glass-pill` / `.glass-icon-btn`** | 与上个 ADR 一脉相承，彻底消除漂移 | 提示词胶囊 `.prompt-chip` 配方略有差异（blur 24 / .55），统一会产生**轻微视觉变化** |
| 材质收敛 | B 只改 KBPill 与附件按钮，不抽共享类 | 改动最小 | 下次升级必然再漏（不满足防复发） |
| 图标移除 | **A 全局移除**（两页一致） | 一致；AgentOptions 是共享组件 | 聊天页也会变化 |
| 图标移除 | B 仅落地页移除（加 prop 控制） | 聊天页不变 | 同一控件两种形态，引入新的不一致 |
| 发送按钮 | **A 保持实心强调色** | 主操作语义清晰 | — |
| 发送按钮 | B 一并玻璃化 | 更统一 | 削弱主操作辨识度 |

## 6. 防复发机制

1. **单一事实源**：胶囊/按钮材质只在 `main.css`。
2. **扩展守卫测试**（`material.test.js`）：
   - 禁止组件内出现 `.ao-btn`/`.to-btn`/`.search-capsule`/`.icon-btn`/`.attach-btn` 的材质声明（噪点、`blur(22px) saturate(180%)`、`1.5px solid var(--border-strong)` 作为"旧平面控件"特征）；
   - 断言上述 5 个控件均引用共享类。
3. **文档**：`main.css` 注释补充"可点击表面必须复用 `.glass-pill` / `.glass-icon-btn`"。

## 8. 决策（Checkpoint，2026-09-21 用户确认）

1. **图标移除范围**：**全局移除**（两个页面一致）。
2. **提示词胶囊**：**不并入 `.glass-pill`**。用户明确"过度统一会丧失区分度"，要求输入框与提示词胶囊
   **更拟物化**，通过**突出 / 嵌入**与背景拉开层次。
3. **发送按钮**：**保持实心强调色**（主操作，不参与层叠系统）。

> 用户已确认方向，进入 Phase 3 实现。

## 9. 实现结果（Phase 3/4 完成后回填）

### 9.1 视觉方向变更（用户在执行中直接修订）

用户在实现期间直接修订了 `main.css`，**否决了"凹槽/嵌入"方向**，改为：

> 风格：**凸起毛玻璃**（frosted glass）——不做凹槽、不做重拟物。
> 区分度来自**强度梯度**（模糊半径 / 投影强度 / 尺寸），**而非方向对立**。

最终配方（全部为凸起：顶部内高光 + 外投影）：

| 类 | 模糊 | 渐变 | 投影 | 用途 |
|---|---|---|---|---|
| `.glass-input` | 28px | .62/.4 | `0 2px 6px` + `0 10px 28px` | 输入框（主表面） |
| `.glass-pill` | 22px | .68/.44 | `0 2px 8px` | 胶囊 |
| `.glass-chip` | 20px | .5/.3 | `0 2px 8px` | 提示词胶囊（最轻） |
| `.glass-icon-btn` | 18px | .66/.42 | `0 2px 7px` | 圆形图标按钮 |

**教训**：上一版设计把"区分度"理解为**方向对立**（嵌入 vs 凸起），但凹槽方向与整体玻璃语言冲突；
正确做法是**同方向 + 强度梯度**。守卫测试 T7 已按最终方向固化（断言全部含顶部内高光与外投影、
无 `inset 0 2px`，且模糊半径满足 input > pill > chip > icon 的严格递减）。
