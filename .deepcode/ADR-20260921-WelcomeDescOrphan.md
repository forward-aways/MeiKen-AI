# ADR-20260921：落地页副标题孤字折行

- 状态：已确认（用户 Checkpoint 通过），实现中
- 日期：2026-09-21
- 影响面：`frontend/src/components/Dashboard.vue`、`frontend/src/__tests__/material.test.js`

---

## 1. 问题陈述

落地页副标题「你的 AI 助手 — 可以问我任何问题、头脑风暴、写代码，或者聊聊天」的最后一个字「天」单独折到第二行（孤字）。

## 2. 根因分析

| 层级 | 内容 | 证据 |
|---|---|---|
| 症状 | 末字「天」单独换行 | 用户观察 |
| 直接原因 | 文案渲染宽度（≈466px）略超容器 `max-width: 460px`，末字被挤到下一行 | `Dashboard.vue:173` `.dashboard p { max-width: 460px; font-size: 15.5px }`；文案见 `i18n.js:5` |
| **根因** | **容器宽度按固定像素写死，与文案实际宽度之间没有约束关系**——只要文案比容器宽出少量像素，就必然产生"孤字"，且任何文案微调/换语言都会复发 | 同上 |

### 泛化判断

| 问题 | 一次性 / 一类 | 代表输入 | 反例 | 非适用场景 |
|---|---|---|---|---|
| 固定宽度导致孤字 | **一类**：固定 `max-width` + 可变动文案 | 落地页副标题 | `.descCode` / `.descWork`（同容器，宽度落在临界点即复发） | 宽度余量充足的长文案（正常折行、无孤字） |

## 3. 设计方案（用户确认：方案 A）

```css
.dashboard p {
  max-width: 520px;      /* 460 → 520：让当前文案整句一行放下 */
  text-wrap: pretty;     /* 浏览器主动避免孤字，与文案长度无关 */
  /* 其余不变 */
}
```

不变量：
- I1：副标题容器必须声明 `text-wrap: pretty`（防复发核心：断行策略不依赖具体文案长度）。
- I2：容器宽度需留有余量，不得与文案宽度处于临界（当前 520px vs ≈466px）。

**为何不选其他方案**
- 仅 `text-wrap: pretty`：Firefox 等尚不支持该属性，降级后仍会孤字。
- 仅加宽 `max-width`：治标；下次改文案或切换语言后可能再次孤字。
- `text-wrap: balance`：会重排多行文案的断行位置（影响面超出本问题）。

**复杂度**：O(1)，纯 CSS。

## 4. 防复发机制

`material.test.js` 新增守卫：断言 `.dashboard p` 同时包含 `text-wrap: pretty` 与不小于 500px 的 `max-width`。

- `Dashboard.vue`：`.dashboard p` 增加 `text-wrap: pretty`，`max-width` 460 → 520px。
- `material.test.js`：新增 T1 守卫。
- 验证：前端 `40 passed`；构建成功。
- 待实机验证：浅色/暗色 + 中英文落地页副标题断行自然；窄屏无溢出。
